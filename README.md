# 裸K复盘 · 在线版（GitHub Pages）

纯静态版本：没有后端，行情直接由浏览器请求币安 / OKX，标注、交易、笔记存在**浏览器本地**（localStorage）。

## 本地预览

在上级目录执行：

```powershell
node serve-web.js
```

打开 <http://127.0.0.1:8789>。

> 直接双击 index.html（file://）也能打开，但部分浏览器会拦截跨域请求，建议用上面的方式预览。

## 装到手机桌面（去掉浏览器地址栏）

站点带 PWA 配置（`manifest.webmanifest` + `sw.js`），可以像 App 一样装到桌面：

1. 手机 Chrome 打开线上地址
2. 右上角 ⋮ → **安装应用**（或「添加到主屏幕」）
3. 从桌面图标打开，**没有地址栏**，整屏都是图表

> 装好后如果界面是旧版，把应用从后台划掉重开一次（联网会取最新文件）。

## 部署到 GitHub Pages

1. 新建一个仓库（public 最省事）。
2. 把本目录（`web/`）里的**全部文件**传到仓库根目录：

```
index.html
app.js
backend.js
style.css
vendor/klinecharts.min.js
```

3. 仓库 → Settings → Pages → Source 选 `Deploy from a branch`，Branch 选 `main`、目录选 `/ (root)`，Save。
4. 等 1 分钟左右，访问：

```
https://你的用户名.github.io/仓库名/
```

以后更新，只要覆盖上传这几个文件即可（浏览器可能缓存，强制刷新一次）。

## 和电脑版的区别

| | 电脑版（server.js） | 在线版（GitHub Pages） |
| --- | --- | --- |
| 要开电脑吗 | 要 | 不要 |
| 数据存哪 | 电脑 `data/` | 浏览器 localStorage |
| 多设备同步 | 手机和电脑共用一份 | **各存各的，不互通** |
| 访问口令 | 有（局域网访问时） | 没有（网址公开，数据在各自浏览器） |
| 功能 | 全部 | 全部（回放、画线、交易、笔记、导出） |

## 注意

- **数据只在这个浏览器里**。换浏览器、清缓存、换手机都会看不到之前的记录。
- 重要记录请用「备份」（导出 JSON）或「导出 MD」保存，换设备时没法直接导入（可以手工整理）。
- localStorage 一般有 5MB 上限，正常使用（几百条标注和交易）够用；如果提示保存失败，先导出备份。
- 公开仓库 = 公开网页。工具本身不包含你的数据（数据在你浏览器里），所以别人打开只会看到空白的自己的一份。
- 国内访问 `github.io` 有时不稳定，需要代理。
